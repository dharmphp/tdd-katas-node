# TDD Katas (Node.js)

Classic coding katas worked test-first with nothing but `node:test` and `node:assert`.
No framework, no build step. Each kata lives in `src/` with its spec in `test/`.

| Kata | Focus |
|---|---|
| FizzBuzz | the warm-up |
| Roman numerals | both directions, strict parsing |
| Bowling game | scoring rules, lookahead |
| String calculator | incremental requirements, custom delimiters |
| Tennis | state as score, naming |
| Mars rover | commands, wrapping grid, obstacles |
| Gilded Rose | refactoring under a characterisation test |

```bash
npm test
```

Requires Node 20+.
